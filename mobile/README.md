# تطبيق المندوب

هذا المجلد مخصص لتطبيق المندوب (Flutter مقترح).

## لماذا لم يُنسخ من Rayyan Pro؟

واجهة المندوب في Rayyan Pro مبنية بـ React
(`RepresentativeMobilePOSPage.tsx` — 193 KB) وتعمل داخل Electron.
التطبيق الأصلي (Native) يحتاج إعادة بناء للواجهة فقط.

## لكن الجزء الصعب جاهز

**عقد الـ API والسلطة المالية منسوخان بالكامل** عبر سكربت الفصل:

| المهاجرة | ما توفّره |
|---|---|
| `087_representative_offline_drafts_idempotency` | مسودات أوفلاين + مفاتيح عدم التكرار |
| `089_financial_idempotency` | منع الازدواجية المالية على مستوى القاعدة |
| `111_representative_mobile_live_location` | تتبّع الموقع اللحظي |
| `177_representative_currency_rate_quote_authority` | تثبيت سعر الصرف لحظة العملية |

## القاعدة الحاكمة

التخزين المحلي على الجهاز **ليس سلطة مالية**.
الجهاز يسجّل *نية* العملية مع مفتاح عدم تكرار،
والخادم وحده يحسب الأرصدة والتحصيل.

هذا ما تضمنه المهاجرتان `087` و `089` — لا تلتفّ عليهما.
